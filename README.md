# TadTor

โปรแกรมตัดต่อวิดีโอบน Windows ใช้งานแบบ CapCut เขียนด้วย Rust + [egui](https://github.com/emilk/egui) (วาดหน้าจอด้วยการ์ดจอผ่าน wgpu) และใช้ [FFmpeg](https://ffmpeg.org) จัดการวิดีโอ/เสียง ทำซับไทยอัตโนมัติในเครื่องด้วย [whisper.cpp](https://github.com/ggml-org/whisper.cpp) และให้ AI (เช่น Claude) ช่วยตัดต่อผ่าน MCP ได้

## ความสามารถ

- **ตัดต่อพื้นฐาน** — แทร็กหลักต่อคลิปอัตโนมัติ แยก/ตัดหัวท้าย/ย้าย/ลบ ลากวางจาก File Explorer พรีวิวพร้อมเสียง Undo/Redo
- **ข้อความ** — สไตล์สำเร็จรูป ฟอนต์ในเครื่อง ขอบ เงา กล่องพื้นหลัง ภาพเคลื่อนไหวตอนเข้า/ออก/วนซ้ำ
- **ซับไตเติล** — ถอดเสียงอัตโนมัติ (ไทย อังกฤษ ญี่ปุ่น จีน เกาหลี) แบ่งบรรทัดตามคำไทย แก้ทีละบรรทัด นำเข้า/ส่งออก .srt
- **ภาพ** — ฟิลเตอร์ ปรับสีละเอียด LUT (.cube) เอฟเฟกต์ ทรานซิชัน 34 แบบ จัดวางภาพ (ซูม เลื่อน หมุน กลับด้าน)
- **เสียง** — ระดับเสียง เฟด เปลี่ยนเสียง เปลี่ยนคีย์ เสียงทุ้ม/แหลม ลดเสียงรบกวน
- **ส่งออก MP4** — H.264 / H.265 ด้วย CPU หรือการ์ด Nvidia (NVENC) ความละเอียด 480p–4K
- **ให้ AI ช่วยตัดต่อ (MCP)** — ตัดช่วงเงียบอัตโนมัติ ตัดตามคำพูด ใส่ซับ ใส่ข้อความ ฯลฯ
- **หน้าจอปรับได้** — ลากสลับที่การ์ด ปรับขนาดตัวอักษร

## เริ่มใช้งาน

### สิ่งที่ต้องมี

1. **Windows 10/11 (64 บิต)**
2. **Rust** — ติดตั้งจาก [rustup.rs](https://rustup.rs) พร้อม **Visual Studio Build Tools** (เลือก "Desktop development with C++") ตามที่ตัวติดตั้ง Rust แนะนำ
3. **FFmpeg** — ดาวน์โหลดรุ่น full build จาก [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) แล้วแตกไฟล์ไว้ในโฟลเดอร์ `ffmpeg\` ของโปรเจกต์ (ให้มี `ffmpeg\bin\ffmpeg.exe` และ `ffmpeg\bin\ffprobe.exe`) หรือติดตั้งให้อยู่ใน PATH เช่น `winget install Gyan.FFmpeg`

### คอมไพล์และเปิดโปรแกรม

```bat
run.bat          :: คอมไพล์แบบเร็วที่สุด สร้างทางลัด TadTor บนเดสก์ท็อป + เมนู Start แล้วเปิดโปรแกรม
run.bat debug    :: แบบ debug มีหน้าต่าง cmd แสดง log (ใช้ตอนพัฒนา)
```

ครั้งแรกใช้เวลาราว 5–15 นาที หลังจากนั้นเปิดจากไอคอน **TadTor** บนเดสก์ท็อป ในโฟลเดอร์โปรเจกต์ ในเมนู Start หรือกด **`Ctrl + Alt + T`** จากที่ไหนก็ได้ (ไม่มีหน้าต่าง cmd) สร้างทางลัดใหม่ได้ที่ **เมนู > สร้างทางลัดบนเดสก์ท็อป** หรือจะใช้ `cargo run` / `cargo build --release` ตรง ๆ ก็ได้

จะนำ `tadtor.exe` ไปใช้เครื่องอื่น ให้วางโฟลเดอร์ `ffmpeg\` (ที่มี `bin\ffmpeg.exe`) ไว้ข้างไฟล์ `.exe`

## วิธีใช้

1. **นำเข้าไฟล์** — กด "+ นำเข้า" หรือลากไฟล์วิดีโอ/เสียง/รูปมาวาง
2. **ใส่ลงไทม์ไลน์** — ลากการ์ดไฟล์ลงไทม์ไลน์ หรือดับเบิลคลิก
   - วิดีโอและรูปไปอยู่ **แทร็กหลัก** คลิปต่อกันอัตโนมัติไม่มีช่องว่าง
   - เสียง/เพลงไปอยู่ **แทร็กเสียง** วางตรงไหนก็ได้
3. **ตัดต่อ** — คลิกเลือกคลิป • ลากกลางคลิปเพื่อย้าย • ลากขอบซ้าย/ขวาเพื่อตัดหัว/ท้าย • ปุ่ม 🔊 ที่หัวแทร็กปิด/เปิดเสียงทั้งแทร็ก
4. **ดูพรีวิว** — กด `Space` หรือคลิกที่ภาพ
5. **ส่งออก** — ปุ่ม "ส่งออก" มุมขวาบน
   - ความละเอียด 480p–4K • 15–60 fps • คุณภาพ สูง/มาตรฐาน/ไฟล์เล็ก/กำหนดเอง (CRF 12–40)
   - H.264 (เล่นได้ทุกที่) หรือ H.265 (ไฟล์เล็กกว่า) • ความเร็ว เร็ว/สมดุล/ละเอียด • เสียง AAC 96–320 kbps
6. **บันทึกงาน** — `Ctrl+S` ได้ไฟล์ `.tadtor` (เก็บแค่ที่อยู่ไฟล์สื่อ อย่าย้าย/ลบไฟล์ต้นฉบับ) ลากไฟล์ `.tadtor` มาวางเพื่อเปิด
   - **บันทึกอัตโนมัติ** ทุก 3 นาที (ปรับได้) แถบบนบอกว่าบันทึกล่าสุดเมื่อไร
   - งานที่ยังไม่เคยบันทึกจะเก็บสำรองไว้ ถ้าโปรแกรมปิดกะทันหันจะถามให้ **กู้คืน** ตอนเปิดครั้งหน้า
   - **เมนู > เปิดงานล่าสุด** (จำ 10 งาน) และเปิดงานล่าสุดให้เองตอนเปิดโปรแกรม

### การตั้งค่า (เมนู > การตั้งค่า หรือ `Ctrl+,`)

- **การบันทึกงาน** — เปิดงานล่าสุดตอนเปิดโปรแกรม • บันทึกอัตโนมัติ เปิด/ปิด และทุกกี่นาที • ล้างรายการงานล่าสุด
- **โปรเจกต์ใหม่** — อัตราส่วน ความละเอียด เฟรมเรต เริ่มต้น
- **พรีวิว** — คุณภาพภาพพรีวิว ลื่น (360p) / สมดุล (540p) / คมชัด (720p)
- **ส่งออก** — โฟลเดอร์เริ่มต้น
- **หน้าจอ** — ขนาดตัวอักษร การจัดการ์ด ไทม์ไลน์บน/ล่าง
- ค่าที่ตั้งไว้ รวมถึงค่าในแท็บซับไตเติล จำไว้ที่ `%LOCALAPPDATA%\TadTor\settings.json` • มีปุ่มคืนค่าเริ่มต้นทั้งหมด

### ข้อความ (แท็บ "ข้อความ")

- **เพิ่มข้อความ** — กดปุ่มหรือ `T` ข้อความไปอยู่ที่หัวเล่น แก้คำ ขนาด สี ขอบ เงา พื้นหลัง ตำแหน่ง ได้ที่แผงรายละเอียด
- **สไตล์สำเร็จรูป** — ไม่ได้เลือกข้อความ = เพิ่มใหม่, เลือกอยู่ = เปลี่ยนสไตล์ (คงคำและฟอนต์เดิม) ชี้เมาส์ที่การ์ดเพื่อดูตัวอย่างแบบขยับ
- **ภาพเคลื่อนไหว** — ตอนเข้า/ออก: จาง เลื่อน ซูม เด้ง • วนซ้ำ: ลอย เต้นตุบ โยก สั่น กระพริบ • ปรับจังหวะ ระยะ ความเร็ว ความแรงได้
- **ฟอนต์** — เลือกจากฟอนต์ในเครื่อง ค้นหาได้ กรองเฉพาะฟอนต์ที่มีภาษาไทยได้

### ซับไตเติล (แท็บ "ซับไตเติล")

- **สร้างซับอัตโนมัติ** — ทำงานในเครื่องทั้งหมด ไม่ส่งไฟล์ขึ้นอินเทอร์เน็ต
  - เลือกภาษา ช่วงที่ถอด (ทั้งงาน / คลิปที่เลือก / จากหัวเล่น) ความยาวบรรทัด สไตล์ซับ และ "คำเฉพาะ" (ชื่อ/ศัพท์ที่พูดถึง ช่วยให้สะกดถูก)
  - โปรแกรมหาช่วงที่มีเสียงพูดก่อนส่งให้ whisper เวลาซับจึงตรงกับเสียง และแบ่งบรรทัดด้วยตัวตัดคำภาษาไทยของ Windows
  - ครั้งแรกจะดาวน์โหลด whisper.cpp และโมเดล `large-v3-turbo` ราว 580 MB ไว้ในโฟลเดอร์ `whisper\` ใช้ CPU เวลาประมาณเท่าความยาวช่วงที่ถอด
- **แก้ซับ** — รายการทุกบรรทัด คลิกเวลาเพื่อกระโดดไป แก้คำได้ทันที • เลื่อนเวลาซับทั้งหมด ±0.1/±0.5 วิ • ใช้สไตล์ซับที่เลือกกับทุกบรรทัด
- **นำเข้า/ส่งออก .srt**

### ภาพ (แท็บ "ฟิลเตอร์" "ปรับแต่ง" "เอฟเฟกต์" "ทรานซิชัน")

เลือกคลิปในแทร็กหลักก่อน แล้วเลือกในแท็บ
- **ฟิลเตอร์** 9 แบบ ปรับความเข้มได้
- **ปรับแต่ง** ความสว่าง คอนทราสต์ ความอิ่มสี อุณหภูมิสี ความคม ขอบมืด เฉดสี เขียว-ม่วง ส่วนสว่าง ส่วนมืด จางฟิล์ม เม็ดฟิล์ม + ไฟล์ LUT (.cube)
- **เอฟเฟกต์** 8 แบบ ปรับความแรง 0–200%
- **ทรานซิชัน** 34 แบบ ยาว 0.1–3 วิ ใช้กับทุกรอยต่อได้ในคลิกเดียว (หรือคลิกรูปเพชรตรงรอยต่อในไทม์ไลน์) ทรานซิชันทำให้คลิปซ้อนกัน งานจะสั้นลงเท่าความยาวทรานซิชัน
- **จัดวางภาพ** (แผงรายละเอียด) — พอดีจอ / เต็มจอ / ยืดเต็ม • ซูม 10–400% • เลื่อน • หมุน 90° • กลับด้าน • สีพื้นหลัง

### เสียง

- แผงรายละเอียดของคลิปที่มีเสียง: ระดับเสียง 0–200% • เฟดเข้า/ออก • เปลี่ยนคีย์ ±12 ครึ่งเสียง • เสียงทุ้ม/แหลม ±12 dB • ลดเสียงรบกวน
- แท็บ "เสียง": เปลี่ยนเสียง ชิปมังก์ ทุ้ม หุ่นยนต์ โทรศัพท์ ก้อง ห้องโถง
- ช่วงทรานซิชัน เสียงสองคลิปค่อย ๆ ข้ามกันอัตโนมัติ

### ตัวเลื่อนค่าและหน้าจอ

- **ตัวเลื่อน** — คลิกตรงไหนของรางก็ไปค่านั้น • `Shift` + ลาก = ปรับละเอียด • ดับเบิลคลิกหรือปุ่ม ↺ = คืนค่าเริ่มต้น • พิมพ์ค่าในช่องตัวเลขได้
- **ย้ายการ์ด** — ลากจุดจับ ⠿ ที่หัวการ์ดไปปล่อยบนการ์ดอื่นเพื่อสลับที่ ลากไทม์ไลน์ไปครึ่งบน/ล่างของจอเพื่อย้ายบน/ล่าง • **เมนู > จัดหน้าจอ** มีแบบสำเร็จรูป
- **ขนาดตัวอักษร** — เมนู > จัดหน้าจอ เลือก 90–150% หรือ `Ctrl +` / `Ctrl −` / `Ctrl 0`
- โปรแกรมจำการจัดหน้าจอไว้ที่ `%LOCALAPPDATA%\TadTor\layout.json`

## ให้ AI ช่วยตัดต่อ (MCP)

`tadtor.exe --mcp` เป็นเซิร์ฟเวอร์ [MCP](https://modelcontextprotocol.io) แบบ stdio ที่ส่งคำสั่งต่อไปยังโปรแกรมที่เปิดอยู่ AI แก้ไทม์ไลน์ได้สด ๆ บนจอ สั่งเป็นภาษาพูดได้เลย เช่น "ตัดช่วงเงียบออกให้หมด" "ทำซับไทยแล้วตัดตรงที่พูดผิดออก"

**Claude Code** (คัดลอกคำสั่งได้จากแผงรายละเอียดของโปรเจกต์ หัวข้อ "เชื่อมต่อ AI (MCP)"):

```bat
claude mcp add tadtor -- "C:\path\to\tadtor.exe" --mcp
```

**Claude Desktop** (`claude_desktop_config.json`):

```json
{ "mcpServers": { "tadtor": { "command": "C:\\path\\to\\tadtor.exe", "args": ["--mcp"] } } }
```

- ยังไม่ได้เปิดโปรแกรม AI จะเปิดให้เอง • ทุกอย่างที่ AI แก้ กด `Ctrl+Z` ย้อนได้ และมีข้อความแจ้งที่มุมจอ
- เครื่องมือ: ดูไทม์ไลน์ • นำเข้า/ใส่คลิป • แยก ตัดหัวท้าย ย้าย ลบ • ตัดช่วงเวลาออก (ripple ทุกแทร็ก) • หา/ตัดช่วงเงียบ • สร้าง/อ่าน/แก้ซับ • เพิ่มข้อความ • ปรับเสียง/สี/เอฟเฟกต์/ทรานซิชัน/จัดวางภาพ • undo/redo • บันทึก • ส่งออก
- โปรแกรมรับคำสั่งผ่าน `127.0.0.1` เท่านั้น และต้องมีรหัสลับที่สุ่มใหม่ทุกครั้งที่เปิด (เก็บใน `%LOCALAPPDATA%\TadTor\control.json`)

```
  ui/                  หน้าจอ
    layout.rs          จัดวางการ์ด ลากสลับที่ ขนาดหน้าจอ
    top_bar.rs         แถบบน (เมนู บันทึก ส่งออก)
    media_panel.rs     การ์ดสื่อและแท็บเครื่องมือ
    tools_panel.rs     แท็บข้อความ/เสียง/เอฟเฟกต์/ทรานซิชัน/ฟิลเตอร์/ปรับแต่ง
    subtitle_dialog.rs แท็บซับไตเติล + หน้าต่างความคืบหน้า
    preview.rs         การ์ดเครื่องเล่น
    inspector.rs       การ์ดรายละเอียด
    timeline.rs        การ์ดไทม์ไลน์
    fader.rs           ตัวเลื่อนค่า
    export_dialog.rs   หน้าต่างส่งออก
    dialogs.rs         หน้าต่างถามบันทึกงาน
    settings_dialog.rs หน้าต่างการตั้งค่า + ถามกู้คืนงาน
assets/                ไอคอนโปรแกรม (icon-source.png = ต้นฉบับ) และฟอนต์ไอคอน
```

## แก้ปัญหาที่พบบ่อย

- **`linker 'link.exe' not found`** → ยังไม่มี Visual Studio Build Tools (C++)
- **แผงรายละเอียดขึ้น "ไม่พบ FFmpeg"** → วาง FFmpeg ไว้ที่ `ffmpeg\bin\` หรือใน PATH แล้วกด "ตรวจใหม่"
- **การ์ด Nvidia ใช้ไม่ได้** → อัปเดตไดรเวอร์การ์ดจอ (FFmpeg รุ่นใหม่ต้องใช้ไดรเวอร์ 610 ขึ้นไป) ระหว่างนี้ส่งออกด้วย CPU ได้
- **สร้างซับอัตโนมัติไม่ได้ / ดาวน์โหลดค้าง** → เช็กอินเทอร์เน็ตแล้วลองใหม่ (ดาวน์โหลดต่อจากเดิมได้) หรือลบโฟลเดอร์ `whisper\`
- **ซับคำผิด** → ใส่ชื่อ/ศัพท์ในช่อง "คำเฉพาะ" แล้วสร้างใหม่ หรือแก้ในแท็บ "ซับไตเติล"
- **AI เชื่อมต่อไม่ได้** → แผงรายละเอียดหัวข้อ "เชื่อมต่อ AI (MCP)" ต้องขึ้น "พร้อมรับคำสั่ง" • หลัง `claude mcp add` ให้เปิด Claude Code ใหม่ • ถ้าย้าย `tadtor.exe` ต้องเพิ่มคำสั่งใหม่
- **คลิปขึ้นสีแดง "ไม่พบไฟล์"** → ไฟล์ต้นฉบับถูกย้ายหรือลบ ย้ายกลับที่เดิมแล้วเปิดโปรเจกต์ใหม่
- **คอมไพล์ error แปลก ๆ เกี่ยวกับที่อยู่ไฟล์** → ลองย้ายโปรเจกต์ไปโฟลเดอร์ที่ชื่อเป็นภาษาอังกฤษ เช่น `C:\tadtor`
